## 跨平台电子书阅读器 Reeden

[Reeden](https://reeden.app) 是一款功能强大的纯本地电子书阅读器，支持多种格式，提供丰富的阅读体验和个性化设置。

支持 `Windows`、`Mac`、`Linux`、`iOS`、`Android` 平台。


## 核心功能

- [x] 全平台数据同步，支持 Webdav、S3、Icloud 协议云存储。
- [x] 丰富的书籍格式，支持 TXT、EPUB、MOBI、AZW、AZW3、PDF
- [x] 阅读历史统计，多时间粒度查看各种阅读数据指标，了解自己的阅读习惯。
- [x] AI 助手，支持 OpenAI 协议的任意模型，预置获取当前阅读信息工具供 AI 调用。
- [x] 笔记，多颜色与样式的笔记记录方式，支持导出成文本与卡片图片。
- [x] 阅读器排版，完全可自定义的排版，你想要的样子都可以有。
- [x] 听书，支持系统语音引擎、Azure 语音引擎。且支持三方 HTTP 方式导入引擎，[文档](https://docs.reeden.app/tts_custom)。
- [x] 阅读目标，可以设定自己的每日目标，提升阅读动力。
- [x] 更多功能可下载体验。
